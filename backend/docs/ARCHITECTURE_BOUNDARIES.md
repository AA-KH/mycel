# Architecture Boundaries

| Domain | Owns | Does Not Own |
|--------|------|--------------|
| **Organization** | company/team structure | execution |
| **Workforce** | employees/capabilities | execution |
| **Team** | domain methodology | runtime |
| **Employee** | specialist identity | tool execution |
| **Agent** | AI execution identity | hiring |
| **Runtime** | execution lifecycle | reasoning definition |
| **Reasoning** | reasoning strategy | tool execution |
| **Tools** | actions | employee identity |
| **Artifacts** | deliverables | reasoning |
